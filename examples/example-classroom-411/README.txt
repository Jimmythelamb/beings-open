Example Classroom 411 (synthetic only)
=====================================

A complete synthetic Test election, code BEINGS-2026-EX411X, with sample
ballot identifiers SAMP41100001 through SAMP41100006. Posted on Flare
Coston2 on 18 November 2026 (America/Vancouver). It is not a real vote,
is never certification-ready, and is labelled as a Test / classroom example.

Names, crypto-wallet addresses and figures in these files are fake
placeholders. There are no real ballot codes and no personal identity
documents in this folder.

Source of the JSON, records, receipts and sample printout: the local
export of the Example 411 working copy. The receipts.json here is
the posted receipts file (status: posted; 10 transactions; election
code BEINGS-2026-EX411X).

Binaries: the unmarked ballots.pdf, marked-ballots.pdf and the six
synthetic ballot-image PNGs (images/) sit beside the JSON. They were
exported from pull request #30 (head
f101c9952c86b1049a08df3c0548c4e65293bfa6).
